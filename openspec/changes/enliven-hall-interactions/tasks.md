# Make the range and galleries respond

## 1. A brass bell that swings and settles (HALL-01)

- [x] 1.1 Show the bell’s physical response and reset state throughout a scored cycle using the defaults in the matching requirement. Shoot twice before reset and once after it and compare pose, sound and tally.

## 2. Hear which bell rang (HALL-02)

- [x] 2.1 Let listeners locate a scored bell in the gallery using the defaults in the matching requirement. Ring the outer bells separately and together, verify the five notes and the listener-space audio path.

## 3. A readable shared bell tally (HALL-03)

- [x] 3.1 Draw attention to the shared count at the moment it changes using the defaults in the matching requirement. Test two scored bells, a score jump on reconnect and a remote player’s hit.

## 4. Carpet and stone underfoot (HALL-04)

- [x] 4.1 Let the player hear the surface actually underfoot using the defaults in the matching requirement. Walk across both intersecting runners, push against the tree, then cross a portal and return.

## 5. Movement in the mitten (HALL-05)

- [x] 5.1 Tie optional mitten movement to actual walking distance using the defaults in the matching requirement. Strafe, push into a wall and stop. Compare the reticle, camera and projectile directions with a static weapon.

## 6. A quiet knock for a sealed door (HALL-06)

- [x] 6.1 Acknowledge a deliberate try at a future door using the defaults in the matching requirement. Walk past three locked arches and deliberately use just the middle one twice.

## 7. An invitation after the last visitor (HALL-07)

- [x] 7.1 Draw attention to the practice bell after the last clear using the defaults in the matching requirement. Clear the final wisp, join from a second client and compare the local accents with the lasting invitation.

## 8. A practice bell answers the group (HALL-08)

- [x] 8.1 Acknowledge one accepted practice restart for the group using the defaults in the matching requirement. Have two clients request practice together and return from a fixture mission separately. Count only accepted practice accents.

## 9. Midnight in the hall (HALL-09)

- [x] 9.1 Mark a newly due date accurately for friends already present using the defaults in the matching requirement. Cross midnight with an empty catalog, then enter late and resume after several days.

## 10. Tune in play and verify controls
